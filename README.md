# 🎧 EchoShadow 1314 — 英文口說 Shadowing 智能跟讀學習系統

> 一款專為**英文跟讀法（Shadowing）**設計的跨平台口說學習系統，結合 YouTube 知名英語學習頻道 **「English Podcast 1314」**（陪你一生一世學好英文）的情境風格與智能造句練習！

---

## 🌟 核心特色與功能一覽

### 1. 🎧 片語跟讀與情境造句
* **自訂片語輸入**：輸入任何想學習的英文片語（如 `call it a day`, `cut corners`, `hit the nail on the head` 等）。
* **Podcast 1314 風格深度語境剖析**：解釋使用時機、口語情緒氛圍與連音弱讀技巧。
* **母語級日常生活例句**：提供最地道的生活會話句子，支援 **Karaoke 即時單字同步高亮跑馬燈**。
* **雙人日常情境對話（A & B）**：模擬 Podcast 實境對談，示範最道地的應答方式。
* **跟讀循環（Shadowing Loop）**：支援 1遍 / 3遍黃金次數 / 5遍強化 / 10遍挑戰 / 無限循環，並可自訂 **1~4 秒跟讀停頓間隔**，留足口說跟讀時間。

### 2. 🔤 單字簡單造句與重複聽播
* **自訂單字輸入**：輸入生詞（如 `procrastinate`, `overwhelmed`, `awkward`, `spontaneous` 等）。
* **【簡單造句】核心體驗**：拒絕冗長難懂的學術長句，專注於 **6~12 字生活高頻短句**，好讀好記，極利於磨練口腔肌肉記憶！
* **詞性、音標與備用例句**：完整附帶 KK/IPA 音標、核心中文釋義與第二個日常簡例。

### 3. ⭐「我的最愛」與片語/單字分區管理
* **一鍵收藏**：在片語、單字或推薦卡片上點擊 **⭐「加入最愛」**，隨時加入精選清單。
* **分區切換**：
  * 🌟 **全部項目**：完整查看所有學習足跡。
  * ⭐ **我的最愛**：快速溫習星號收藏的精華內容。
  * 🎧 **片語專區**：專注複習慣用語、情境短語與雙人對話。
  * 🔤 **單字專區**：專注複習核心詞彙與簡單短句。
* **即時統計**：動態顯示片語篇數、單字個數與收藏總數。

### 4. 📻 YouTube「English Podcast 1314」精選片語庫
* 精選 30+ 頻道高頻道地美式俚語與成語，支援職場、社交、日常與情緒等情境分類。
* 分級標籤：A2 基礎慢速、B1 中階日常、B2 流利道地。
* 支援關鍵字搜尋、「🎲 換一批推薦」與「🎧 立即跟讀」一鍵載入工作台。

### 5. 📱 手機免安裝商店解決方案（PWA 全平台相容）
針對部分手機**「無法安裝第三方 APK」**或 **「iPhone 封閉無法側載」** 的問題，本 APP 全面採用 **PWA（Progressive Web App）** 技術：
* **免去 App Store / Google Play 繁瑣審核與付費**。
* **無任何 APK 惡意軟體警告或安裝失敗風險**。
* **iOS (iPhone/iPad)**：使用 Safari 打開網址 ➔ 點擊底部「分享」➔ 點選 **「加入主畫面」(Add to Home Screen)** 即可！
* **Android (安卓全機型)**：使用 Chrome 打開網址 ➔ 點擊 **「安裝應用程式」** 即可自動常駐桌面！
* **手機點開即是獨立全螢幕 App**，附帶專屬霓虹耳機 App 圖示。

### 6. 🎙️ 跟讀錄音與原音對比（Audio Echo）
* 支援透過麥克風錄製自己當前的口說發音。
* 可隨時點擊「▶ 聽我剛剛說的」與「🔊 對比聽原音」，檢查自己的重音、連音與語調。

## 🚀 本機啟動方式

### 方法一：雙擊啟動腳本（最簡單推薦）
直接雙擊執行目錄中的：
* **`start.bat`** 或 **`start.ps1`**
系統將自動啟動本機伺服器並在預設瀏覽器中開啟 `http://localhost:8765`。

### 方法二：透過命令列啟動
在專案目錄下執行：
```powershell
py -3 server.py
```
接著在瀏覽器打開：`http://localhost:8765`

## 📤 如何上傳至 GitHub 獨立專案 (`shadowing`)

本目錄已初始化為獨立的 Git 儲存庫並完成初次提交。上傳至您的 GitHub 帳號步驟如下：

1. 前往 GitHub 建立一個名為 **`shadowing`** 的新倉庫：
   👉 **[https://github.com/new](https://github.com/new)**
   * Repository name 填寫：`shadowing`
   * 選擇 Public 或 Private
   * **不要勾選** "Initialize with a README"（因為本機已有完整檔案）
   * 點擊 **Create repository**

2. 建立完成後，直接在資料夾雙擊執行：
   * **`push_to_github.bat`** 或在 PowerShell 執行 `.\push_to_github.ps1`
   系統便會自動將全部專案檔案推送到：
   👉 `https://github.com/hunter072088/shadowing`

## 📱 手機在同一個 Wi-Fi 下連線

當電腦與手機連在同一個家用或公司 Wi-Fi 時：
1. 點擊 APP 右上角 **「📱 手機安裝」** 按鈕，畫面將自動顯示您電腦的區域 IP（例如 `http://192.168.1.202:8765`）與 QR Code。
2. 用手機相機掃描 QR Code 或在手機瀏覽器輸入該網址。
3. 按照指示選擇「加入主畫面」或「安裝應用程式」，即刻享受極速手機版口說跟讀！
