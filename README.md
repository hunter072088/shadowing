# 🎧 EchoShadow 1314 — 英文口說 Shadowing 智能跟讀學習系統

> 一款專為**英文跟讀法（Shadowing）**設計的本機端口說學習 APP，結合 YouTube 知名英語學習頻道 **「English Podcast 1314」**（陪你一生一世學好英文）的情境風格與智能造句練習！

---

## 🌟 核心功能與使用者需求對應

### 1. 🎧 片語跟讀與情境造句（需求 1）
* **自訂片語輸入**：輸入任何你想掌握的英文片語（如 `call it a day`, `cut corners`, `hit the nail on the head` 等）。
* **Podcast 風格深度解析**：AI 自動解析其語境氛圍（什麼時候用、口語語氣、細膩情感）。
* **母語級日常生活造句**：生成自然道地的美式生活例句。
* **雙人日常情境對話（A & B）**：模擬 Podcast 1314 實境對話，展示最地道的開口方式。
* **跟讀循環（Shadowing Loop）**：
  * 可切換**單次、3遍黃金次數、5遍強化、10遍挑戰或無限循環**。
  * 自訂每次跟讀之間的**停頓間隔（1秒、2秒、3秒、4秒）**，留足口說跟讀時間。
  * 即時 **Karaoke 跑馬燈單字高亮**，眼看耳聽口唸完美同步。

### 2. 🔤 單字簡單造句與跟讀（需求 2）
* **自訂單字輸入**：輸入任何生詞（如 `overwhelmed`, `procrastinate`, `awkward`, `spontaneous` 等）。
* **極簡日常造句（用戶指定需求）**：拒絕冗長複雜的學術長句，專注於 6~12 字生活高頻短句，朗朗上口，極利於磨練口腔肌肉記憶！
* **音標與詞性解析**：KK / IPA 音標與核心中文翻譯。
* **備用例句與發音重點**：提供第二個簡單生活例句與發音易錯點解析。
* **一鍵重複聽播跟讀**。

### 3. 📻 YouTube「English Podcast 1314」精選片語庫（需求 3）
* **精選 30+ 高頻道地美式片語**（涵蓋職場應對、朋友社交、日常生活、情緒表達）。
* **分級標籤**：A2 基礎慢速、B1 中階日常、B2 流利道地。
* **即時搜尋與分類過濾**：可根據情境與程度迅速查找。
* **「🎲 換一批推薦」**：隨機產生與推薦最新生活片語。
* **一鍵即時跟讀**：點擊卡片上的「🎧 立即跟讀」按鈕，立即無縫載入到底部跟讀工作台開始練習！

### 4. 🎙️ 跟讀錄音與原音對比（Audio Echo）
* 支援透過麥克風錄製自己當前的跟讀發音。
* 可隨時點擊「▶ 聽我剛剛說的」與「🔊 對比聽原音」，檢查自己的重音、連音與語調（Intonation）。

### 5. 📚 生詞與歷史複習筆記
* 自動記錄每一次查詢與跟讀過的片語與單字。
* 隨時溫故知新，支援一鍵再次練習或刪除。

## 🚀 啟動方式

### 方法一：雙擊啟動腳本（最簡單推薦）
直接雙擊執行目錄中的：
* **`start.bat`** 或 **`start.ps1`**
系統將自動啟動本機伺服器並在預設瀏覽器中開啟 `http://localhost:8765`。

### 方法二：透過命令列啟動
在專案目錄下執行：
```powershell
py -3 server.py
```
接著在瀏覽器打開：`http://localhost:8765`

---

## ⌨️ 快捷鍵支援
* **`Space`（空白鍵）**：播放 / 暫停當前跟讀循環
* **`Esc`**：停止播放

---

## ⚙️ 進階設定（右上角齒輪）
* **聲音選擇（TTS Voice）**：可挑選系統內建的 Microsoft Jenny, Google US English 等高品質英語聲音，並支援一鍵試聽。
* **預設語速**：0.75x（慢速磨耳朵）、0.9x（新手推薦）、1.0x（標準語速）、1.15x（進階挑戰）。
* **停頓時間**：自訂每次播完後給予的口說模仿時間（1s ~ 4s）。
* **Gemini API Key（可選）**：若填入 API Key，系統將以 Gemini 2.5 Flash 即時生成最新穎的例句；若未填寫，系統內建的智能離線生成引擎亦 100% 完美運作！
